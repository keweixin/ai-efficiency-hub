适合谁

鉴权处理如果写死 token，用例很快失效，也难以切换环境和角色。面试时要说明如何让登录态可维护。

从搜索用户的角度看，接口自动化 token 鉴权不是一个只需要概念解释的问题。真正有帮助的页面应该告诉读者先做什么、怎样检查结果、哪些地方需要回到官方资料或原始材料核验。所以本文不追求堆关键词，而是把流程拆成能照着做的动作。

核心方法

把登录接口封装成前置步骤，token 存在会话上下文或统一请求头。不同权限准备不同账号，关键接口验证未授权和权限不足。

  1. 封装登录方法，不在用例里写死 token。
  2. 统一请求头和环境配置。
  3. token 过期时重新登录并记录日志。
  4. 为普通用户、管理员和无权限用户准备账号。
  5. 断言业务码和权限提示。

常见错误

  • 把 token 复制到每条用例。
  • 只测正常登录用户。
  • 没有覆盖未授权和权限不足。
