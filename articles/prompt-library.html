四段式公式

稳定 Prompt 不靠玄学，先写清楚角色、目标、约束和输出格式。角色决定视角，目标决定任务，约束决定边界，输出格式决定可用性。

通用模板

你是【角色】。我需要完成【目标】。背景信息是【素材】。请遵守【约束】。最后请按【输出格式】返回，语言要适合【受众】。

三个场景

  • 学习：请扮演课程助教，把这章内容整理成考试复习表。
  • 求职：请扮演面试官，围绕我的项目经历追问。
  • 写作：请扮演编辑，把这段文字改得更清晰，但不要改变原意。

如何沉淀模板

把好用的 Prompt 存成“场景 + 输入 + 输出 + 注意事项”的格式。每次使用后补充失败案例，模板会越来越稳定。
